GAIA agent, Hugging Face Agents Course Unit 4

This Space holds the source code of a smolagents CodeAgent that answers the 20 GAIA Level 1 questions of the final assignment. Browse the code under Files.

  • agent.py: builds the agent, wraps each question, scrubs answers into exact-match shape
  • tools.py: web search, page reading, Wikipedia as of a date, file readers, audio transcription, image analysis, YouTube frames, chess board reading plus Stockfish
  • run_local.py: harness that runs questions, caches answers, and submits
  • app.py: Gradio version of the same agent (needs a Gradio Space to run)

Brain: Grok 4.6 through LiteLLM. Hearing: Gemini. Chess: Stockfish 19.
